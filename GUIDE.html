۱

بررسی ویندوز

  1. روی Computer (یا This PC) کلیک راست کنید و Properties را بزنید.
  2. در قسمت System type باید نوشته باشد 64-bit.
  3. اگر ویندوز ۷ است، باید Service Pack 1 هم نوشته شده باشد.
اگر 32-bit بود یا Service Pack 1 نداشت، ادامه ندهید و با فروشنده‌ی نرم‌افزار تماس بگیرید.
۲

دریافت فایل‌های نصب

سه فایل لازم است. همه از GitHub دانلود می‌شوند (یا فروشنده با فلش به شما می‌دهد):

فایلبرای چه
VC_redist.x64.exeپیش‌نیاز ویندوز برای XAMPP
xampp-…-7.4…-installer.exeوب‌سرور و دیتابیس
Git-…-64-bit.exeدریافت و آپدیت نرم‌افزار (اختیاری)

صفحه‌ی دانلود فایل‌های نصب

هر سه فایل را در یک پوشه، مثلاً روی دسکتاپ، ذخیره کنید.
۳

نصب Visual C++

  1. روی VC_redist.x64.exe دوبار کلیک کنید.
  2. تیک I agree را بزنید و Install را بزنید.
  3. اگر نوشت قبلاً نصب شده (Repair / Uninstall)، فقط Close را بزنید؛ یعنی لازم نیست.
  4. اگر خواست کامپیوتر را Restart کنید، این کار را بکنید.
۴

نصب XAMPP

  1. روی فایل xampp-…-installer.exe دوبار کلیک کنید. اگر پیام هشدار (UAC یا آنتی‌ویروس) آمد، OK یا Yes را بزنید.
  2. در صفحه‌ی Select Components فقط این‌ها تیک داشته باشند: Apache، MySQL، PHP، phpMyAdmin. بقیه را بردارید.
  3. در صفحه‌ی پوشه‌ی نصب، همان C:\xampp را بگذارید و عوض نکنید.
  4. Next را تا آخر بزنید و صبر کنید تا نصب تمام شود.
  5. در پایان، تیک Do you want to start the Control Panel now را بگذارید و Finish را بزنید. زبان را English انتخاب کنید.
۵

روشن کردن Apache و MySQL

  1. XAMPP Control Panel را باز کنید: منوی Start ← XAMPP Control Panel. بهتر است با کلیک راست ← Run as administrator باز شود.
  2. جلوی Apache و MySQL، تیک ستون Service (سمت چپ) را بزنید و هر سؤال را با Yes جواب دهید. این کار باعث می‌شود با روشن شدن کامپیوتر خودکار روشن شوند.
  3. جلوی هر دو، دکمه‌ی Start را بزنید. اسمشان باید سبز شود.
اگر Apache سبز نشد: احتمالاً برنامه‌ی دیگری (مثل Skype یا IIS) از پورت ۸۰ استفاده می‌کند. آن برنامه را ببندید و دوباره Start بزنید.
۶

نصب Git

اگر قرار است نرم‌افزار را با فلش بگیرید (بدون اینترنت)، این قدم را رد کنید.

  1. روی فایل Git-…-64-bit.exe دوبار کلیک کنید.
  2. در همه‌ی صفحه‌ها فقط Next بزنید، چیزی را عوض نکنید، و در آخر Install و Finish.
۷

دریافت نرم‌افزار

یکی از دو راه زیر:

راه الف: با Git (پیشنهادی)

آپدیت‌های بعدی با یک دوبار-کلیک انجام می‌شوند.

راه ب: با فلش (فایل zip)

اگر اینترنت ندارید یا Git نصب نکردید.

راه الف: با Git

  1. در منوی Start، برنامه‌ی Git Bash را باز کنید.
  2. این دستور را کپی کنید، در Git Bash کلیک راست ← Paste کنید و Enter بزنید (کلید دسترسی این کامپیوتر را می‌سازد):
    ssh-keygen -t ed25519 -C "printshop" -f ~/.ssh/printshop_release -N ""
  3. این دستور را هم بزنید:
    cat ~/.ssh/printshop_release.pub
    یک خط طولانی نمایش داده می‌شود که با ssh-ed25519 شروع می‌شود. آن را انتخاب کنید (با ماوس بکشید)، کلیک راست ← Copy، و برای فروشنده‌ی نرم‌افزار بفرستید (مثلاً در تلگرام).
  4. صبر کنید تا فروشنده بگوید «اضافه شد».
  5. این دستور را بزنید:
    printf 'Host github-printshop\n HostName github.com\n User git\n IdentityFile ~/.ssh/printshop_release\n' >> ~/.ssh/config
  6. و در آخر این دستور (نرم‌افزار را در جای درست دریافت می‌کند):
    git clone git@github-printshop:Alipishdad99/printshop-release.git /c/xampp/htdocs/printshop
    اگر پرسید Are you sure you want to continue connecting، بنویسید yes و Enter بزنید.
درست انجام شد اگر: پوشه‌ی C:\xampp\htdocs\printshop ساخته شده و داخلش فایل install.bat هست.
اگر خطای Permission denied آمد: یعنی کلید هنوز اضافه نشده؛ با فروشنده هماهنگ کنید و قدم آخر را دوباره بزنید.

راه ب: با فلش

  1. فایل printshop-v….zip را از فروشنده بگیرید.
  2. روی آن کلیک راست ← Extract All، و مسیر را C:\xampp\htdocs بدهید.
درست انجام شد اگر: پوشه‌ی C:\xampp\htdocs\printshop هست و داخلش install.bat. (نه یک پوشه‌ی printshop داخل پوشه‌ی printshop دیگر.)
۸

نصب نرم‌افزار

  1. مطمئن شوید MySQL در XAMPP Control Panel سبز است.
  2. پوشه‌ی C:\xampp\htdocs\printshop را باز کنید و روی install.bat دوبار کلیک کنید.
  3. یک پنجره‌ی سیاه باز می‌شود و ۷ مرحله را خودش انجام می‌دهد. چیزی را نبندید تا بنویسد Done.
  4. در XAMPP Control Panel، جلوی Apache یک بار Stop و بعد Start را بزنید.
این فایل همه‌ی کارهای فنی را خودش انجام می‌دهد: ساخت دیتابیس و جدول‌ها، تنظیمات، اطلاعات اولیه و پشتیبان‌گیری خودکار هر شب. لازم نیست چیز دیگری نصب کنید.
اگر نوشت MySQL is not running: MySQL را در XAMPP روشن کنید و دوباره install.bat را بزنید. اجرای دوباره ضرری ندارد.
۹

اولین ورود

  1. مرورگر (Chrome یا Firefox) را باز کنید و بنویسید: http://localhost
  2. با نام کاربری و رمزی که فروشنده داده وارد شوید.
  3. همان اول از منوی کاربران، رمز همه‌ی کاربرها را عوض کنید.
  4. از منوی تنظیمات، نام فروشگاه، تلفن و نشانی را برای فاکتور وارد کنید.
  5. از منوی محصولات، محصولات و قیمت‌های خود را وارد کنید.
راهنمای داخل برنامه: در هر صفحه دکمه‌ی «راهنما» یا کلید F1 توضیح کامل همان صفحه را نشان می‌دهد.
۱۰

استفاده از کامپیوترهای دیگر شبکه

  1. روی همین کامپیوتر (سرور)، در منوی Start بنویسید cmd، روی آن کلیک راست ← Run as administrator.
  2. این دستور را بچسبانید و Enter بزنید (اجازه‌ی ورود از شبکه در فایروال):
    netsh advfirewall firewall add rule name="Printshop" dir=in action=allow protocol=TCP localport=80
  3. برای پیدا کردن آدرس این کامپیوتر، این دستور را بزنید و عدد جلوی IPv4 Address را بردارید (مثلاً 192.168.1.10):
    ipconfig
  4. روی کامپیوترهای دیگر، در مرورگر همان عدد را بنویسید، مثلاً http://192.168.1.10
نکته: این کامپیوتر همیشه باید روشن باشد تا بقیه بتوانند کار کنند. بهتر است آدرس IP آن ثابت شود (از کسی که شبکه را راه انداخته بخواهید).
۱۱

آپدیت کردن (هر بار که فروشنده خبر داد)

اگر با Git نصب کرده‌اید

  1. مطمئن شوید MySQL روشن است.
  2. در پوشه‌ی C:\xampp\htdocs\printshop روی update.bat دوبار کلیک کنید.
  3. بعد از Updated، در مرورگر Ctrl+F5 بزنید.

اگر با فلش نصب کرده‌اید

  1. فایل zip جدید را بگیرید، کلیک راست ← Extract All به C:\xampp\htdocs، و اگر پرسید جایگزین شود، Replace.
  2. روی update.bat دوبار کلیک کنید و بعد Ctrl+F5.
اطلاعات شما در امان است: update.bat قبل از هر کاری از اطلاعات پشتیبان می‌گیرد؛ اگر پشتیبان‌گیری نشد، آپدیت را انجام نمی‌دهد.
۱۲

پشتیبان‌گیری و مشکلات رایج

  • هر شب ساعت ۲۲ خودکار پشتیبان گرفته می‌شود (اگر کامپیوتر روشن باشد).
  • از داخل برنامه، منوی پشتیبان‌گیری، هر وقت خواستید پشتیبان بگیرید یا اطلاعات را برگردانید.
  • هر هفته پوشه‌ی C:\xampp\htdocs\printshop\backup را روی فلش کپی کنید. اگر هارد خراب شود، فقط همین نسخه نجاتتان می‌دهد.
مشکلراه‌حل
برنامه باز نمی‌شود یا صفحه‌ی XAMPP می‌آیددر XAMPP Control Panel، Apache را Stop و Start کنید.
خطای اتصال به دیتابیسMySQL را در XAMPP Control Panel روشن کنید.
از کامپیوتر دیگر باز نمی‌شودقدم ۱۰ (فایروال) و درست بودن آدرس IP را بررسی کنید.
update.bat نسخه‌ی جدید را نمی‌گیرداینترنت را بررسی کنید؛ اگر درست نشد، با فروشنده تماس بگیرید یا با فلش آپدیت کنید.
ظاهر برنامه بعد از آپدیت عوض نشدهدر مرورگر Ctrl+F5 بزنید.
